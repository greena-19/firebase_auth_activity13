Firebase Authentication – In-Class Activity 13

Project Overview
This is a Flutter application created for In-Class Activity 13. It uses Firebase Authentication to let users register with an email and password, sign in, view their profile, change their password, and sign out. The app switches between the authentication and profile screens based on the user's sign-in state.

Features
- Register: Create an account with an email address and password.
- Sign in: Log in using an existing account.
- Input validation: Check required fields and show helpful error messages.
- Password visibility: Show or hide the password while typing.
- Authentication state: Use authStateChanges() to display the appropriate screen.
- Profile: Display the signed-in user's email address.
- Change password: Ask for the current password, reauthenticate the user, and update the password.
- Sign out: Return to the authentication screen after signing out.

Project Structure
lib/
├── main.dart
├── firebase_options.dart
├── screens/
│   ├── authentication_screen.dart
│   └── profile_screen.dart
└── services/
    └── auth_service.dart
- main.dart initializes Firebase and listens for authentication-state changes.
- firebase_options.dart contains Firebase configuration generated by FlutterFire.
- auth_service.dart keeps Firebase Authentication operations in one place.
- authentication_screen.dart handles registration and sign-in.
- profile_screen.dart displays the user email and provides password-change and sign-out actions.
How to Run
1. Install Flutter and set up an Android emulator or a connected device.
2. Clone the repository:
   git clone https://github.com/greena-19/firebase_auth_activity13.git
   cd firebase_auth_activity13
3. Install dependencies:
   flutter pub get
4. Make sure the app is configured for your Firebase project and Email/Password is enabled in Firebase Authentication. If setting up a new Firebase project, use the FlutterFire CLI to generate the appropriate configuration:
   flutterfire configure
5. Run the application:
   flutter run
